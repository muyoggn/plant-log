## 2. フォルダの役割

```
src/
  app/                 ← ページ。フォルダ名がそのまま URL になる
    page.tsx           ← トップ（/）：部屋の図と植物
    plants/new/        ← /plants/new：登録
    plants/[id]/       ← /plants/abc123：植物ごとのページ（[id] は「ここに番号が入る」の意味）
    settings/          ← /settings：場所の設定
  components/          ← 画面の部品（水分ゲージ、部屋の図 RoomView など）
  data/plants.ts       ← 植物の育て方データ（ここに足すと選べる植物が増える）
  data/furniture.ts    ← 部屋に置ける家具の種類とサイズ
  lib/                 ← 画面以外の処理
    storage.ts         ← 記録の保存（localStorage）
    weather.ts         ← 天気の取得（Open-Meteo）
    wiki.ts            ← 説明と写真の取得（Wikipedia）
    watering.ts        ← 水やりの目安の計算
    light.ts           ← 部屋の中の日当たりの見積もり
```

## 3. 「use client」とは？

ページの先頭に `"use client";` と書いてあるファイルは、**ブラウザの中で動く**部品です。
このアプリは記録をブラウザ（localStorage）に保存するので、記録を読むページはすべてブラウザで動かす必要があります。
サーバーには localStorage がないため、サーバーで作る段階では「読み込み中…」と表示しています。

## 4. 水やりの目安の計算（`src/lib/watering.ts`）

鉢の土の水分を **ゲージ（100% → 0%）** として考えます。

1. 水やりした日は 100%
2. 毎日、その日の天気に合わせて減っていく
   - 1 日に減る量 = 1 ÷（その日の気温での水やり間隔）× 湿度の補正
   - 水やり間隔は、植物ごとの「25℃のとき」と「10℃のとき」の目安の間を、気温でなめらかにつなぐ
   - 30℃ を超える日はさらに乾きやすい / 空気が乾いていると多めに減る
3. 0% になる日が「次の水やりの目安」
4. 屋外の植物は、5mm 以上の雨が降った日に 100% に戻る

室内は外より気温の上下がおだやかなので、外の気温を半分くらいにやわらげて計算しています
（外 0℃ → 室内 10℃、外 30℃ → 室内 25℃ くらい）。どれも大まかな仮定なので、
使いながら「早すぎる・遅すぎる」と感じたら数字を調整していきましょう。

## 6. 部屋の図に植物を置く（2026-11-24）

トップページを「自分の部屋を上から見た図（間取り図）」に変えました。

### 図の描き方：SVG
部屋の図は **SVG（エスブイジー）** で描いています。SVG は「(10, 20) から幅 100 の四角」のように、
図形を数字で指定して描く方法です。ライブラリはいらず、React の中にそのまま `<rect>` や `<circle>` を書けます。
`viewBox` という設定で「この図は横 360、縦 270 の世界です」と決めておくと、画面の大きさに合わせて自動で拡大・縮小されます。
このアプリでは **1 = 1cm** にしているので、家具や部屋の大きさをそのまま cm で書けます（`src/components/RoomView.tsx`）。

### ドラッグで動かすしくみ
1. 植物の丸に指（マウス）が触れたら「つかんだ位置」を覚える（`onPointerDown`）
2. 指が動くたびに、画面上の位置を部屋の cm に変換して、仮の位置で描きなおす（`onPointerMove`）
3. 指を離したら、最後の位置を保存する（`onPointerUp`）。少ししか動いていなければ「タップ（選択）」として扱う

マウスでもスマホの指でも同じ「Pointer イベント」で受け取れるので、1 つの書き方で両方に対応できます。

### 日当たりの見積もり（`src/lib/light.ts`）
- 窓に近いほど明るい（2.5m 離れると窓の光はほぼ届かないと考える）
- 窓の向きで強さを変える：南 1.0、東・西 0.8、北 0.5
- 窓が 2 つ以上あれば足し合わせる

これを「日なた / 明るい日陰 / 日陰」の 3 段階に分け、床の黄色の濃さで表示しています。
植物ごとの好み（`src/data/plants.ts` の `lightRange`）と比べて「暗すぎ・明るすぎ」を教えてくれます。

### 水やりの計算にも反映
室内の植物は、明るい場所ほど土が早く乾くと考えて、1 日に減る水分を「暗い場所 ×0.85 〜 窓ぎわ ×1.15」で調整しています。
